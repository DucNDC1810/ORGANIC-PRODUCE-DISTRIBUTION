📡 API ENDPOINTS

  CREATE PAYMENT
  POST /api/momo/create-payment
  Auth: Required
  Response: {payUrl, deeplink, qrCodeUrl, momoOrderId, requestId, ...}

  WEBHOOK CALLBACK
  POST /api/momo/callback
  Auth: None (Public)
  Body: {partnerCode, orderId, amount, resultCode, signature, ...}

  QUERY PAYMENT
  POST /api/momo/query-payment
  Auth: Required
  Response: {orderStatus, paymentStatus, amount, transId, ...}

  TEST CALLBACK (Development)
  POST /api/momo/test-callback
  Auth: Required
  For offline testing without MoMo redirect

🔄 PAYMENT FLOW

  User Checkout
      ↓
  Select MoMo Payment Method
      ↓
  Backend: Create Order & Payment Record
      ↓
  Generate Signature (HmacSHA256)
      ↓
  Call MoMo API
      ↓
  Receive Payment Link
      ↓
  Redirect to MoMo Page
      ↓
  User Enters Credentials
      ↓
  MoMo Processes Payment
      ↓
  [Parallel] Callback to Backend
      ↓
  Backend: Verify Signature
      ↓
  Update Payment Status: "paid"
      ↓
  Update Order Status: "confirmed"
      ↓
  MoMo Redirects to App
      ↓
  App: Display Payment Result Page
      ↓
  User Sees Success / Error / Pending
      ↓
  localStorage: Auto-cleanup
